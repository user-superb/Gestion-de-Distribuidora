# Gestion de Distribuidora - "Tutucas"
Proyecto para la materia de Ingeniería de Software de la Facultad de Informática (UNLP).

## Enunciado del proyecto
Coordinación y gestión logística de repartos para comercios de barrio: control de pedidos, trazabilidad de hojas de ruta, despacho y conciliación contra entrega.


## Estructura

- `backend/`: API REST (Node + Express + PostgreSQL). La app móvil usa `/api/movil`.
- `frontend/`: aplicación de escritorio para la administración (React + Vite).
- `mobile/`: aplicación móvil del transportista (Expo). Ver [`mobile/README.md`](mobile/README.md).
- `docs/requerimientos/`: historias de usuario, decisiones y preguntas pendientes por épica.
