# Gestion de Distribuidora
Proyecto para la matería de Ingeniería de Software de la Facultad de Informática (UNLP)

## Enunciado del proyecto
¡Hola! Soy Martín y trabajo coordinando repartos para varios comercios de barrio. Todos los días recibimos pedidos que tenemos que entregar a distintos clientes y, aunque el negocio fue creciendo, seguimos organizándonos de manera bastante informal.

Actualmente coordinamos gran parte de los repartos por WhatsApp y cada vez se nos hace más difícil llevar un buen control. Por eso pensé: ¿y si tuviéramos un sistema que nos ayudara a organizar y gestionar mejor todo el proceso de entregas? Estoy dispuesto a invertir en una solución que nos ayude a resolver este problema.
